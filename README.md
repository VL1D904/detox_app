Веб приложение для детоксикации сообщений на русском языке с использованием нейросетевых моделей
-
Инструкция по запуску
- 
1. Скопируйте репозиторий git clone https://github.com/VL1D904/detoxicApp
2. Заполните необходимые поля в .env.template и переименуйте в .env
2. В директории с проектом выполните: docker compose up --build
3. В браузере перейдите по маршруту: http://127.0.0.1:8000/

Функционал:
-
- Отправка сообщения на детоксикацию (до 150 символов)
- Анализ преобразованного сообщения на токсичность
- Сравнение смысловой схожести отправленного и преобразованного сообщений
- Возможность создания аккаунта через подтверждение email
- Авторизация через сторонние сервисы (Google, Yandex, Github)
- Сохранение истории запросов авторизованного пользователя
- Кэширование последних запросов пользователей

Стек технологий:
-
- Веб приложение реализовано на микрофреймворке Flask
- Для преобразования токсичного текста в нейтральный, была дообучена нейросетевая модель nllb-200-distilled-600M на датасете u_paradetox_content
- Для оценки токсичности и смысловой схожести используются нейросетевые модели с hugging face russian_toxicity_classifier и gte-multilingual-base соответственно 
- Для хранения данных используется СУБД MySQL
- Для повышения скорости ответа используется кэширование последних запросов на Redis
- Для контейнеризации и развертнывания используется Docker
